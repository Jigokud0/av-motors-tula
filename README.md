# Ав-моторс — Тула

Адаптивный сайт автосервиса «Ав-моторс» с реальными фотографиями мастерской, услугами, галереей, отзывом, контактами и подготовкой обращения в MAX. Подготовлен для импорта в Lork из публичного GitHub-репозитория.

## Импорт в Lork

Выберите импорт GitHub-репозитория и вставьте URL этого репозитория. Корень проекта — корень репозитория.

- Стек: React 18 + Vite 6, JavaScript/JSX.
- Установка: `npm ci`.
- Сборка: `npm run build`.
- Результат: `dist/`.
- Node.js: 20.19+ или 22+.
- Корневой `tsconfig.json` включён: сборка проходит TypeScript, затем Vite.
- Все изображения и шрифты локальные. Сервер, база данных, ключи и переменные окружения не нужны.

Создание репозитория не означает импорт или публикацию сайта в Lork. Последующие изменения GitHub необходимо переносить в импортированный проект отдельно, если синхронизация не подключена.

## Локальный запуск

```sh
npm ci
npm run dev
```

Для проверки готовой сборки: `npm run build`, затем `npm run preview`.

## Что работает

Шесть направлений ремонта, выбор услуги с переходом к обращению, адаптивное меню, увеличение фотографий с листанием (включая клавиши ←/→ и Escape), FAQ, звонок, маршрут в Яндекс Картах и ссылка MAX из публичной карточки компании.

Посетитель указывает автомобиль и проблему, копирует текст обращения, открывает MAX и отправляет его самостоятельно. Время подтверждается сервисом в переписке. Сайт не хранит данные и не имитирует отправку заявки. Копирование требует HTTPS или localhost; при недоступном буфере показана инструкция написать в MAX напрямую.

## Фотографии и шрифты

10 фотографий загружены из публичной карточки компании по просьбе заказчика использовать реальные материалы. Исходные ссылки сохранены в `PHOTO-SOURCES.json`. На сайте используются 7 разных фотографий; остальные доступны в папке для дальнейших правок. Фотографии не обозначены как «до/после». Номера автомобилей намеренно не переписываются в текст.

Manrope хранится в `public/fonts/`; лицензия — `public/fonts/OFL.txt`. Визуальный знак AV создан для этого демо и не выдаётся за существующий официальный логотип компании.

## Редактирование

- `src/main.jsx`: тексты, услуги, контакты, ссылка MAX, галерея и логика обращения.
- `src/style.css`: оформление и адаптивная вёрстка.
- `public/images/`: фотографии WebP.
- `index.html`: заголовок и описание страницы.

Сборка TypeScript + Vite. В браузере проверены ширины 320, 390, 768 и 1440 px, отсутствие горизонтального скролла, мобильное меню, галерея и листание, раскрытие FAQ, заполнение и копирование обращения. Телефонные ссылки, MAX и маршрут указаны явно; сообщения при проверке не отправлялись.
